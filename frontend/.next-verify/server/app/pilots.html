A pilot is a bounded deployment under a signed agreement, with data and IP terms settled before it starts. Each milestone names the evidence that must be filed, and payment is released only once the department validates it.

Milestones and payment
  1. M1DeployPaid₹3L

    Sensor nodes installed across the three pilot wards and streaming to the municipal gateway.

    Evidence: Installation register · Node connectivity log · Site photographs

  2. M2CollectPaid₹4L

    Thirty days of continuous baseline flow, pressure and acoustic data captured.

    Evidence: Baseline dataset · Data quality report · Uptime record

  3. M3ValidateApproved₹4L

    Detected leak locations verified against physical excavation by the municipal repair team.

    Evidence: Excavation verification sheet · True/false positive analysis

  4. M4ReportEvidence filed₹4L

    Independent validation of the outcome metrics against the contracted target.

    Evidence: Independent validation report · Cost impact statement
